# bliss-paint

Rendering backend for the Bliss engine.

## Overview
Handles the actual drawing operations, converting DOM layout trees into visual pixels. Supports multiple backends including software rasterization and GPU acceleration.

- **Status**: Stable
- **Maintainers**: Antarik Team
