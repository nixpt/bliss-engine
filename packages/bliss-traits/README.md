# bliss-traits

Core traits and interfaces for the Bliss rendering ecosystem.

## Overview
Defines the contract between the rendering engine mechanics and the embedding application (Exosphere). Includes traits for DOM control, event sinking, image caching, and network providers.

- **Status**: Stable
- **Maintainers**: Antarik Team
